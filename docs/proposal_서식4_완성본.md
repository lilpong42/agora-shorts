## 【 4쪽: 제안서 요약 표 】

* **참가 분야:** AI융합콘텐츠분야 (☑) *(빅데이터 분석 융합형)*
* **아이디어 주제:** **Agora-Shorts (아고라 쇼츠)** — 유튜브 악플·설전 댓글 빅데이터를 40초 찬반 핵심 논거 AI 아바타 토론 쇼츠(MP4)로 자동 변환하는 공론장 중재 파이프라인
* **팀명 / 참가자:** 호날두의 아이들 (동양대학교 AI빅데이터융합학과 1학년 김성원, 강휘, 손기윤)

### ■ 아이디어 요약 (5줄 이내)
온라인 뉴스·유튜브 댓글창의 감정적 욕설·혐오 표현과 여론 쏠림(침묵의 나선) 문제를 해결하기 위해, **YouTube Data API v3**로 실시간 댓글 빅데이터를 수집·정화(Detoxification)하고 찬반 양측의 핵심 논거만 추출하는 AI 공론장 중재 서비스이다. 추출된 양측 핵심 논거를 **Google Gemini 2.5 구조화 엔진**과 **Native Audio TTS**, **FFmpeg 비디오 파이프라인**을 통해 **50:50 동등 발언권(총 6턴, 40초)의 9:16 세로형 양자 토론 쇼츠(MP4)**로 자동 생성하여 건전한 숙의 공론장을 조성한다.

### ■ 【 제안서 요약 】 항목별 개조식 정리

* **제안 배경 및 아이디어 소개**
  * ◦ 유튜브·포털 뉴스 댓글창이 감정적 배설과 혐오 표현으로 오염되고, 분노 기반 다수 의견이 80% 이상 과대 대표되어 합리적 소수 의견이 묻히는 '공론장 붕괴' 현상 심화
  * ◦ 실제로 본 팀이 YouTube Data API v3로 3대 사회 갈등 뉴스 영상 12건의 댓글 527건을 실측 분석한 결과, 비속어·공격성 과열 댓글이 23.9%(126건, 평균 과열도 62.8점)에 달했으며 규제 찬성 여론이 78~88%로 편중됨을 확인
  * ◦ 이에 감정적 노이즈는 제거하고 찬성(PRO)과 반대(CON) 양측의 핵심 논거 3가지씩을 추출해 중립적 아나운서 음성의 **40초 9:16 쇼츠 영상(MP4)**으로 자동 제작하는 **Agora-Shorts**를 제안함

* **빅데이터 활용 계획** *(AI융합콘텐츠분야 선택 + 빅데이터 분석 결합)*
  * ◦ **활용 데이터:** YouTube Data API v3(`commentThreads.list`, `videos.list`)를 통해 YTN·MBC·SBS·KBS·연합뉴스TV 등 주요 언론사 사회 갈등 뉴스 영상의 실시간 댓글 텍스트, 추천수(likeCount), 작성 시각 데이터 수집 (사전 실증 표본 N = 527건 구축 완료)
  * ◦ **전처리 및 정량 지표화:** 한국어 비속어·초성 욕설·혐오 어휘 정규식 사전 및 감정 과열도(Empirical Toxicity Score, 0~100점) 산출 알고리즘을 적용하여 악플 필터링 비율과 정화 전후 과열도 이동폭(커널 밀도 추정, KDE) 측정
  * ◦ **시맨틱 키워드 군집화:** 불용어(Stopwords) 제거 후 찬성 측 6대 논거 군집(실측 877회 출현)과 반대 측 6대 논거 군집(실측 510회 출현)의 빈도를 정량 비교하여 대본 생성의 근거 데이터로 활용

* **AI 활용 방법 및 혁신성**
  * ◦ **Google Gemini 2.5 Flash Structured Output:** 수백 개의 파편화된 댓글 군집을 입력받아 `issue_title`, `raw_stats`, `debate_script`(찬반 교차 6턴 배열) JSON 스키마로 오차 없이 구조화하고, 공격적 표현을 아나운서 보도문 톤으로 순화(Detoxification)
  * ◦ **듀얼 보이스 TTS & FFmpeg 9:16 MP4 자동 합성:** Gemini 2.5 Native Audio TTS(남성 중저음 `Kore` / 여성 고음 `Puck`) 및 Web Speech API로 양측 아바타 음성을 분리 합성하고, `rsvg-convert`와 `FFmpeg(libx264)`로 실시간 오디오 파형·자막·카운트다운 바가 포함된 720×1280 MP4 영상을 자동 렌더링
  * ◦ **50:50 기계적 균형 중재 알고리즘:** 원본 댓글의 수적 비대칭성(예: 88 대 12)에 휩쓸리지 않고 양측의 가장 논리적인 핵심 근거 3개씩에 동일한 20초(3턴×6.7초)를 배정하는 알고리즘적 공론장 중재 구현

* **아이디어의 차별성 및 실행 방안**
  * ◦ **기존 서비스 대비 차별성:** 기존 악플 필터링 AI(클린봇 등)는 단순 숨김·삭제에 그쳐 논거까지 소실시키며, 기존 요약 AI는 다수파 의견만 요약해 편향을 강화함. 반면 Agora-Shorts는 **'악플 속 핵심 논거 구출 → 50:50 양자 대립 숏폼 영상화'**라는 독창적 융합 콘텐츠 파이프라인을 구축함
  * ◦ **클라우드 풀스택 실행 환경:** FastAPI 백엔드 + Tailwind 다크모드 스튜디오 UI + **Supabase(PostgreSQL)** 클라우드 DB 저장 + **GitHub(`lilpong42/agora-shorts`)** 오픈소스 및 정적 프리뷰 배포 완료

* **현장 적용 및 발전 가능성**
  * ◦ **언론사·포털 플러그인(B2B SaaS):** 방송사 유튜브 채널 및 네이버·다음 뉴스 하단에 '40초 AI 찬반 요약 쇼츠 보기' 위젯으로 즉시 탑재하거나 방송사 숏폼 채널 자동 제작 솔루션으로 공급 가능
  * ◦ **공공기관·지자체 시민 여론 수렴(B2G):** 조례 제정이나 지역 현안(소음 단속, 공유 킥보드 견인, 고령자 면허 등) 민원 빅데이터를 시각적 카드뉴스 및 숏폼으로 자동 요약하는 디지털 숙의 행정 도구로 확장

* **기대효과 및 ESG 가치**
  * ◦ **실측 감정 과열도 77.1% 감소:** 실증 분석 결과 과열 표본군 평균 과열도를 **62.8점에서 14.4점으로 -48.4pt 감소**시키고 논리성 지수를 **85.6점**으로 끌어올려 디지털 공론장의 피로도와 사회적 갈등 비용 절감
  * ◦ **ESG(Social & Governance) 혁신:** 소수 의견(생계형 라이더, 농어촌 고령층 등)의 생존권·이동권 논거가 다수파의 혐오 표현에 묻히지 않고 동등하게 전달되도록 보장하여 디지털 포용성과 민주적 거버넌스(G) 실현

## 【 5쪽: 제안서 본문 (아이디어 주제: Agora-Shorts / 호날두의 아이들) 】

### 1. 제안 배경 및 아이디어 소개
* **문제 정의 (온라인 공론장의 이중 위기: 혐오 과열과 여론 쏠림):**
  숏폼과 유튜브 뉴스 소비가 일상화되면서 댓글창은 사회적 현안을 논의하는 가장 큰 공론장이 되었으나, 실상은 초성 욕설·조롱·인신공격이 난무하는 감정 배설장으로 변질되었다. 특히 본 팀이 **YouTube Data API v3**를 활용하여 실제 사회 갈등 뉴스 영상 12건의 댓글 527건을 수집·분석한 결과, 두 가지 구조적 문제가 실증적으로 확인되었다.
  1. **감정적 노이즈로 인한 논거 매몰:** 전체 댓글의 **23.9%(126건)**가 비속어·혐오·극단적 공격성을 포함(과열 표본 평균 **62.8점**)하고 있어, 그 안에 담긴 시민들의 정당한 정책적 요구(수면권 보호, 인프라 확충 등)까지 단순 악플로 버려지고 있다.
  2. **분노 편향에 의한 여론 비대칭성:** 실제 뉴스 댓글창에서는 자극적 피해 사례에 분노한 규제 찬성(PRO) 댓글이 **78%~88%**를 차지하여, 생계형 노동자나 농어촌 고령층의 현실적 고충을 담은 반대(CON) 논거(12%~22%)가 완전히 묻히는 '침묵의 나선'과 확증편향이 발생하고 있었다.
* **제안 목적 및 주요 대상:**
  **Agora-Shorts(아고라 쇼츠)**는 이러한 댓글 빅데이터에서 감정적 독성(Toxicity)만 걷어내고 찬반 양측의 핵심 논거(Core Arguments)를 각각 3개씩 대등하게 추출하여, **중립적인 남·여 AI 아나운서가 40초 동안 6턴(각 6.7초)으로 티키타카 토론을 벌이는 9:16 세로형 쇼츠 영상(MP4)**을 실시간 생성하는 서비스이다. 주요 타깃은 ① 댓글창의 피로감 없이 이슈의 양면성을 40초 만에 파악하려는 **숏폼 소비 시민**, ② 댓글 여론을 후속 보도용 숏폼 콘텐츠로 자동 제작하려는 **언론사·크리에이터**, ③ 시민 민원의 핵심 쟁점을 파악해야 하는 **지자체·공공기관**이다.

### 2. 데이터 활용 계획
* **활용 데이터명 및 제공기관:**
  * **데이터명:** 유튜브 방송 뉴스 댓글 텍스트 및 참여 메타데이터 (`commentThreads`, `videos` 리소스)
  * **제공기관:** Google YouTube Data API v3 (공식 REST API 연동)
  * **실증 수집 데이터셋 (`data/real_youtube_comments.json`, 총 N = 527건):**

    2. **이슈 2 (대학가·도심 공유 전동킥보드 즉시 견인 및 금지, N = 180건):** MBC뉴스(`Xt8TRqMuZRc`), SBS뉴스(`aI0awk0NBfc`), TBS뉴스(`D2hNIe74HEQ`)
    3. **이슈 3 (고령 운전자 조건부 면허 및 반납 의무화, N = 147건):** MBC뉴스(`NKIvNrtdiGA`), KBS뉴스(`x3J5hpBci98`, `BNG7q3aDOqU`, `YnBKCrgDvWs`), YTN(`yfAshZpECCo`), KNN(`Wv5awGH1-EM`)
* **데이터 선정 이유 및 구체적인 활용 방법:**
  유튜브 뉴스 댓글은 현안에 대한 시민들의 날것의 여론과 생생한 현장 사례가 가장 빠르게 모이는 비정형 빅데이터다. 본 프로젝트는 사용자가 임의의 유튜브 영상 URL을 입력하면 즉시 **YouTube Data API v3**를 통해 댓글 원문, 작성자, 추천수(`likeCount`)를 수집하고 다음 3단계로 활용한다:
  1. **한국어 공격성·비속어 정량 스코어링:** 정규식 기반 한국어 혐오·비속어 패턴 매칭과 문장 부호 과열도를 결합해 개별 댓글의 `Toxicity Score(0~100점)`를 산출하고 비속어 토큰을 마스킹·제거한다.
  2. **찬반 입장 분류 및 시맨틱 클러스터링:** 형태소·키워드 매칭을 통해 찬성(PRO)과 반대(CON) 여론 점유율을 산출하고, 양측의 상위 6대 핵심 쟁점 군집 빈도를 추출한다.
  3. **클라우드 DB 자산화 (Supabase PostgreSQL):** 분석이 완료된 이슈별 통계(`raw_stats`), 정화 전후 대조 샘플(`detox_samples`), 6턴 토론 대본(`debate_script`), 생성된 MP4 영상 경로를 **Supabase(`agora_debates` 테이블)**에 영구 저장하여 공론장 아카이브로 활용한다.

### 3. AI 활용 방법 및 혁신성
* **활용 AI 기술 및 도구:**
  * **LLM 엔진:** Google Gemini 2.5 Flash (`gemini-2.5-flash`, Structured JSON Schema 강제 출력)
  * **음성 합성(TTS) 엔진:** Gemini 2.5 Flash Native Audio TTS (`gemini-2.5-flash-preview-tts`, 24kHz PCM 듀얼 보이스) 및 Web Speech API 하이브리드 엔진
  * **멀티미디어 렌더링 엔진:** `rsvg-convert` 벡터 그래픽 엔진 + `FFmpeg (libx264 / AAC)` 9:16 세로형 MP4 합성 파이프라인
* **적용 방식 및 AI 활용에 따른 개선 효과:**
  1. **비속어 디톡시피케이션 및 아나운서 화법 재구성 (Style Transfer):**
     예를 들어 실제 수집된 *"단속 의지도 없으면서 ㄱ ㅐ소리!!! 파출소 배달가는 딸배도 붕붕 거리더라"* (과열도 97.5점)라는 원문 댓글에서 비속어(`ㄱ ㅐ소리`, `딸배`)는 제거하되, 그 안에 담긴 *'일선 단속의 실효성 부족 및 상시 단속 체계 강화 필요성'*이라는 핵심 논거만 추출하여 아나운서 보도 문장으로 재구성한다.
  2. **실측 과열도 감소 및 논리성 향상 효과:**
     527건의 실측 댓글에 파이프라인을 적용한 결과, 필터링 대상 과열 표본군(n=126)의 평균 감정 과열도는 **62.8점(SD=15.3)에서 중재 후 14.4점(SD=1.3)으로 -48.4pt(-77.1%) 급감**했으며, 전체 표본(N=527) 평균 과열도 역시 **36.5점에서 14.4점으로 -60.5% 감소**하여 중립·논리적 공론 구간(0~32점) 진입률 **100%**를 달성했다.

### 6. 현장 적용 및 발전 가능성
* **즉시 현장 적용 가능한 하이브리드 아키텍처:**
  실시간 YouTube URL 입력 분석과 함께, 발표 현장 네트워크 장애 시에도 0.1초 만에 즉시 응답하는 실측 기반 프리셋 3종과 사전 렌더링된 9:16 MP4 영상을 내장하여 현장 시연 안정성을 100% 확보했다.
* **사업화 및 확장 로드맵:**
  1. **미디어·크리에이터 B2B SaaS (`Agora-Studio`):** 언론사 유튜브 채널의 댓글창을 매일 자동 분석해 '오늘의 네티즌 찬반 40초 쇼츠'를 자동 업로드하는 구독형 콘텐츠 생성 솔루션으로 사업화.
  2. **지자체·공공기관 디지털 공론장 플랫폼 (B2G):** 국민신문고 및 지자체 입법예고 댓글란에 적용하여 악성 민원의 감정적 표현은 걸러내고 찬반 핵심 정책 근거만 브리핑 영상으로 요약하는 행정 지원 시스템으로 확장.
